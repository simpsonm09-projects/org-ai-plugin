# simpsonm09-projects working agreements
- Work through pull requests. Push a branch to the repository and open the pull request against `main`.
- Open pull requests only against repositories owned by `simpsonm09-projects`, or by `simpsonm09` for the PStack plugin source. Never against a third-party upstream.
- Use `repo-standard` for change gates, the definition of done, and the pull request flow. Use `repo-tasks` for build, test, and verification commands. Use `service-integrations` before reaching a shared service.
- Keep secrets, tokens, and machine-specific paths out of commits, prompts, and logs.
